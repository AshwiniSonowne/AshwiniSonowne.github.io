# Ashwini Sonowne — Data Analyst Portfolio

A responsive personal portfolio website built with HTML and CSS.

## Files
- `index.html` — portfolio content
- `style.css` — visual styling and responsive layout
- `assets/Ashwini_Sonowne_Resume.pdf` — resume linked from the site

## Publish with GitHub Pages
1. Create a new public repository named **AshwiniSonowne.github.io** under your GitHub account.
2. Extract this ZIP on your computer.
3. Upload `index.html`, `style.css`, and the `assets` folder to the repository root (not the ZIP file itself).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait a few minutes and visit `https://ashwinisonowne.github.io/`.

## Before publishing
- Check that all project links point to the correct repositories.
- Add real dashboard screenshots if you want them shown in the project cards.
- Review your resume and contact details before making the site public.
- The project descriptions are introductory; replace them with verified findings or metrics when ready.
